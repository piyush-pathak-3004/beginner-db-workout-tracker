# Beginner DB Workout Tracker

A simple, offline-first web app for absolute beginners using only a **2.5 kg dumbbell pair**.

## Features
- 4-day split:
  - Day 1: Chest + Triceps
  - Day 2: Back + Biceps
  - Day 4: Shoulders + Abs
  - Day 5: Legs + Glutes
- Set-by-set checkboxes that auto-complete exercises and the whole day
- Streak counter + weekly / monthly calendar
- Progress log + notes
- Form cues + easier alternatives for every exercise
- No push-ups, beginner-safe movements only
- Works completely offline (localStorage)

## How to use
1. Open `index.html` in any modern browser (or host it anywhere).
2. Tap the day you want to train.
3. Mark sets as you complete them.
4. When all sets are done the day is automatically marked complete and your streak updates.

## Live Demo
Just open the `index.html` file after cloning/downloading.

## Tech
Pure HTML + CSS + Vanilla JS. No frameworks, no build step, no backend.

Created for consistent habit-building with light equipment.
